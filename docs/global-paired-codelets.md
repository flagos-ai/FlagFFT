# 全局使用成对蝶形

按用户要求，取消上一轮对后端、精度、叶长度和内核类型的限制。
radix 11/13/17/19 的 bundled codelet 直接改为共享正负频率输出的
余弦/正弦累加实现；`emit.py` 不再选择新旧版本，`metadata.py` 恢复统一
读取 bundled codelet。所有使用这四种蝶形的路径都会获得新实现。
其他基数的已有优化蝶形不变。

`paired_codelets.py` 保留为源文件生成工具和数学测试来源，不再参与
运行时选择。测试同时校验生成公式与 bundled 文件一致，并检查普通叶、
四步、strided 和 Bluestein 融合内核都读取统一实现。

此变更取代此前文档中的 209/221 点与 MUSA/CUDA 限制。代码对所有后端
开放；当前硬件验证范围为 MUSA S5000 和 NVIDIA A100。

复测基线为 `944fcd0`，即此前有限定的成对蝶形版本。使用保存的旧 Python
代码生成器区分新旧行为，没有用新源码生成所谓“旧版”内核。

- Python 数学与代码生成测试：84 项通过。
- GPU 补测：2D `143×323`、`23×53`，3D `11×17×19`，覆盖六类 API、
  正逆参考比较和往返。
- 性能补测：C2C/Z2Z forward，2D `143×323`、`23×53`，batch=1，
  out-of-place，warmup=10，iters=50。

- `../results/20260913_105405_a100_global_paired/`
